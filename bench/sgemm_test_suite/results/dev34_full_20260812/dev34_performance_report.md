# dev-3.4.0 KGemm vs 原生 NEON 全量性能报告

## 测试配置

- 分支：`dev-3.4.0`，提交 `00a593da4`。
- 平台：Kunpeng 950 7592C，最高 2.3 GHz。
- 编译器：GCC 12.3.1、Clang 17.0.6。
- 编译参数：`-O3 -DNDEBUG -flto -pthread -DEIGEN_USE_THREADS=1 -DEIGEN_MAX_ALIGN_BYTES=64 -march=armv9-a+nosve`。
- 测试计划：`sgemm_test_plan.csv`，84 个 `(m,k,n)`。
- 每点 7 个样本，每个样本至少 250 ms，使用 median GFLOP/s。
- RowMajor、`C=A*B`；线程 1/2/4/8 分别绑定 CPU 120、120-121、120-123、120-127。
